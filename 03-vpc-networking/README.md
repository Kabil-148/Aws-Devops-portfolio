# AWS VPC Networking

## Objective
Create a basic VPC network with public and private subnets.

## Architecture
VPC → Subnets → Route Tables → Internet Gateway → EC2

## AWS Services
- Amazon VPC
- Subnets
- Route Tables
- Internet Gateway
- EC2
- Security Groups

## Implementation
1. Created VPC.
2. Created public and private subnets.
3. Created and attached Internet Gateway.
4. Configured route tables.
5. Launched EC2 in public subnet.
6. Connected using SSH.
7. Tested internet connectivity.

## Result
Successfully created a VPC network and verified EC2 internet connectivity.
